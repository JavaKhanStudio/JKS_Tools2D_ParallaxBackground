Effects lab

One lab per effect, and one with them all (r224). fog: the page fog (r217) mixes each layer toward the fog's colour by 1 - exp(-strength (1/speed - 1/front)), so the slower a layer scrolls the more it is fogged, the front layer never; the readout gives each layer's fog. snow: a PARTICLES layer's snow (the particles round's snow-wide.p): its density, flake size, wind, its place among the layers, its drift and its anchor. all: every effect that ships, together on the shaders round's s01: the page fog, the FOG mist, the trees' WAVE, a game's towers drawn in an EMPTY layer, and the snow; the right panel is the same page with none. Each page is drawn by the real reader, compiled to JavaScript, as a browser game draws it. The cost line gives the frame time and, per panel, its draw calls and the CPU time to submit them (the GPU's time is in the frame time).
