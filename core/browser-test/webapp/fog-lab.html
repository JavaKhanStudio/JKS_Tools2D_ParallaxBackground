FOG lab how tall should the patches be?

What this lab shows

FOG thins the mist's opacity by a sum of three sines. Across, they run at 7, 17 and 23 waves per 8 wavelengths, so the patches come back the same only every 8 wavelengths (r216); up and down only every 2, 2 and 1.25 wavelengths, so today's patches (A) are 3 to 4 times taller than wide and read as vertical streaks on any band. B halves the heights: patches about as tall as wide. C is the same with a patch height a page would store (a fourth number, an editor slider). The scroll and every slider act on all four panels at once. The lab opens on Simon's r208 settings (shape A, amplitude 0.25, wavelength 8.25, no tree ripple); the mist's layer slider moves the mist in front of more layers. The page fog (r217) mixes every layer toward the fog's colour, more the slower it scrolls (1 - exp(-strength (1/speed - 1/front))), in A to C; the plain panel has neither. The readout gives each layer's fog. The FOG itself only thins the mist picture, a band across the middle: without the page fog, nothing above or below it is fogged: the mist's size and up/down sliders grow and move that band. The parallax set slider puts the same mist into other pages (round1's calm, PurpleFairy and OneNight); every other slider acts on whichever set is shown.
